游标接口：

```text
GET /api/chat/session/list
  page / size / keyword / archived          # 旧参数，兼容
  cursor_last_active_at
  cursor_session_id
  cursor_is_pinned                          # 复合排序键包含置顶位
```

`next_cursor` 结构：

```json
{"last_active_at": "2026-11-12 22:16:40.174724", "session_id": 436, "is_pinned": false}
```

排序键保持 `is_pinned DESC, COALESCE(last_active_at, create_time) DESC, session_id DESC`，SQL 使用 PostgreSQL 行比较；仅为满页时返回 `next_cursor`，最后一页为空。

## 3. 已知限制与后续

1. **首屏口径**：`nav_ms` 包含 Vite dev 冷启动（约 0.9–1.5s），不计入列表验收；列表可用时间按资源 `startTime → 首行 DOM` 计算。
2. **行高为估算值**：28/66px 未用真实测量；当前名称最多两行，实测无重叠；若后续行内容增高需同步调整或改用 `measureElement`。
3. **虚拟阈值 40**：小数据量保持真实 DOM，便于调试与旧行为回归；该值尚未由用户确认。
4. **关闭开关是 localStorage**：未提供界面开关，验收通过 `localStorage['ragknowledge:session-virtual']='off'` + 刷新完成。
5. **触控拖拽未支持**：属于 N11 范围，本阶段未改。
6. **测试账号已清理**：`n1_stress` 及其 500 条会话已删除；admin 现有会话未改动。
