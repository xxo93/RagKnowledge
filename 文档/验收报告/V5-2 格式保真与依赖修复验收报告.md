## 4. 格式保真验收

### DOCX / DOC

后端返回：

```html
<h1>旧版 Word 测试</h1><p>这是一段用于验证 .doc 转换的中文段落。</p><table class="doc-table">…</table>
```

前端截图可见标题为一级标题样式、正文为段落、表格带边框；不再使用等宽纯文本块。

### Excel / XLSX

- 返回 HTML 表格包含 `colspan="3"` 的跨列标题。
- 表头单元格样式包含 `font-weight:600`；底色单元格包含 `background:#1F4E79`。
- 列宽按原表 `column_dimensions` 输出；行高按 `row_dimensions` 输出。
- 375 窄屏为全屏弹窗，表格区域横向滚动，页面横向溢出 `0px`。
- 公式单元格保留公式原文（示例 `=100+200`）。

### XLS / CSV

- `.xls` 使用 `xlrd(formatting_info=True)` 读取格式信息，输出合并单元格、字体、底色、边框和对齐。
- CSV 无原生样式，输出带表头的基础 HTML 表格，不强行套用 Excel 主题。

## 8. 已知边界

- 不承诺页眉页脚、页码、分栏、批注、浮动文本框和 Office 精确分页。
- `.doc` 格式保真仍依赖 LibreOffice 或 Windows WPS/Office COM；无转换器时提示下载原件。
- Excel 图表、条件格式、图片、透视表不进入 HTML 预览；可通过下载原件查看。
- `mammoth` 对复杂 WordArt、SmartArt 和部分域代码只能降级为可读文本。
